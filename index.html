IoT-focused IT student with hands-on experience as an IoT Engineer Intern, building end-to-end systems that connect embedded hardware, real-time data pipelines, and cloud infrastructure.

Selected Projects

01
AWS Bedrock Serverless AI Health

MediGuard — AI Health Platform

Problem

Patients struggle to understand their vital signs and identify appropriate medical specialists for their conditions, leading to delayed or incorrect care decisions.

Approach

Built a fully serverless, AI-powered healthcare platform that accepts vital sign inputs and uses a Bedrock Agent to reason over diagnoses and recommend specialists.

Implementation

Deployed on AWS using Bedrock Agent, Lambda, API Gateway, S3, CloudFront, and CloudFormation for infrastructure-as-code. Frontend built in HTML, CSS, and JavaScript.

AWS Bedrock Agent · Lambda · API Gateway · CloudFormation · S3 · CloudFront
02
ROS 2 SLAM Computer Vision

Autonomous Medical Inventory Robot

Problem

Hospital pharmacy logistics involve repetitive, error-prone manual verification of medications and slow inventory tracking across large facilities.

Implementation

Built an autonomous mobile robot using ROS 2 and SLAM for self-navigation. Integrated a YOLOv8 vision pipeline for medication verification before dispensing. Connected to AWS for real-time cloud dashboard and inventory tracking.

ROS 2 · SLAM · YOLOv8 · OpenCV · AWS Cloud · Arduino · Python · Servo Motor
03
ESP32 LoRa Firebase

Real-Time Flood Monitoring System

Problem

Remote flood-prone areas lack affordable, real-time environmental monitoring infrastructure for early warning systems.

Implementation

Deployed ESP32 nodes with SHT31 (temperature/humidity), rain gauges, and JSN-SR04T waterproof ultrasonic sensors. Used LoRa E5 for long-range, low-power transmission and Firebase for cloud storage. Built a Flutter dashboard for remote visualization.

ESP32 · LoRa E5 · Firebase · Flutter · SHT31 · JSN-SR04T · Arduino IDE
04
ESP32 RFID Google Sheets

RFID Attendance System

Smart attendance system using ESP32 and RC522 RFID reader with Google Sheets as cloud storage. I2C LCD 16×2 provides real-time on-device feedback.

ESP32 · RC522 · I2C LCD · Google Sheets · Arduino IDE
